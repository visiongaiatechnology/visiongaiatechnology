## 👋 我们是谁

**VisionGaiaTechnology 是一家独立、自力更生的技术实验室，由 Rene Körner 创立。** 他 28 岁，常驻德国科隆，目前作为唯一开发者构建整个技术栈——Sir Quacksec 提供高级顾问意见和情感支持。

我们的信念：最重要的软件层不应该向别人租用。这个愿景大于单一产品——**在世界范围内可行的数字主权**，从欧洲构建，设计为在任何地方使用。

我们构建 local-first 系统，具备可验证的行为、透明的架构，并且没有不必要的云依赖——从内核级网络防御到人们日常使用的文档和笔记。

没有大团队。没有大预算。没有戏剧性的路线图。只有可运行的代码、公开仓库和技术栈的下一层。

**我们不是 Enterprise。我们是 Entenprise。** 区别主要在于羽毛，但事实证明羽毛是一种出奇好用的治理模型。

## ⚙️ 我们优化的方向

- **默认 local-first。** 没有云控制平面。没有租来的信任。
- **证据胜于声明。** 测试、清单和审计追踪都是产品的一部分。
- **可逆的强化。** 安全应当可观测、可调整、可恢复。
- **拥有整个技术栈。** 操作系统、安全、生产力，最终还有硬件。
- **在重要之处保持严肃。** 鸭子用来调试。生产用来验证。
