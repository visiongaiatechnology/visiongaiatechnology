## 👋 私たちについて

**VisionGaiaTechnology は、Rene Körner が創業した独立・自己資金のテクノロジーラボです。** 28歳、ドイツ・ケルン在住。現在は唯一の開発者としてスタック全体を構築しています。Sir Quacksec はシニアアドバイスと精神的サポートを提供します。

信念：最も重要なソフトウェアレイヤーを他人から借りるべきではない。ビジョンは単一製品より大きい——**世界中で機能するデジタル主権**。ヨーロッパから構築し、どこでも使えるように設計します。

私たちは検証可能な動作、透明なアーキテクチャ、不要なクラウド依存のない local-first システムを構築します。カーネル近傍のネットワーク防御から、人々が毎日使うドキュメントやノートまで。

大きなチームも、大きな予算も、芝居がかったロードマップもない。あるのは動くコード、公開リポジトリ、そしてスタックの次のレイヤーだけ。

**私たちは Enterprise ではありません。Entenprise です。** 違いは主に羽毛ですが、羽毛は驚くほど優れたガバナンスモデルであることが判明しました。

## ⚙️ 私たちが最適化するもの

- **デフォルトで local-first。** クラウドのコントロールプレーンなし。借り物の信頼なし。
- **主張よりエビデンス。** テスト、マニフェスト、監査トレイルは製品の一部です。
- **可逆的なハードニング。** セキュリティは観測可能で、調整可能で、復旧可能であるべきです。
- **スタック全体を所有する。** OS、セキュリティ、生産性、そして最終的にはハードウェア。
- **大事なところで真面目に。** アヒルはデバッグ用。本番はエビデンス用。
